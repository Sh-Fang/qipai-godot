# 棋类 AI 故意不用最强的引擎

合集以娱乐为主，输到自闭就不好玩了，所以象棋用 ElephantEye（象眼，LGPL-2.1），五子棋自己写棋型打分加浅层搜索，都不用最强的开源引擎 Pikafish 和 Rapfi（两者都是 GPL-3）。

**Considered Options**

- Pikafish：棋力远超人类，但 2023 年起删掉了自带的难度调节，要自己补回来，还要多带 48 MB 的网络文件。
- Fairy-Stockfish：自带难度调节，但是一个支持几十种棋的大引擎，象棋只是其中之一。
- Rapfi：同样远超人类，难度也要自己做。

ElephantEye 不靠神经网络、体积小，自带剪枝、知识和随机性几档设置，加上限制搜索深度就能从很弱调到业余高手；五子棋 AI 自己写最好控制"像人一样失误"。如果以后要加"大师"档，再引入 Pikafish 或 Rapfi。
