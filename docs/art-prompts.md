# 美术素材生图提示词

每行格式是「物品（保存文件名）：提示词」。冒号后面整段直接复制进生图工具，一次生成一个。
生成好的图按括号里的文件名放进 `game/art/` 对应的子目录。
第一张满意的图出来后，后面尽量都拿它当参考图，或者固定种子（seed），这样整套风格才统一。
不支持透明背景的工具，生成出来是白底或绿底都没关系，抠图交给我。
